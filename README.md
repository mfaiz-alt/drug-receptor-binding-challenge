Drug–Receptor Binding Challenge
Interactive drag-and-drop pharmacology quiz for UiTM Diploma in Pharmacy (PH110) students.
Match each drug to the correct receptor using a hidden-name "pharmacological fingerprint" (location, effect, family), with progressive hints and explanations.
Run locally
Open `index.html` in a browser. No build step.
Deploy on GitHub Pages
Push `index.html` and `README.md` to a repository.
Settings → Pages → Deploy from branch → `main` / root.
Scoring
No hint +10 · Hint 1 +8 · Hint 2 +6 · Hint 3 +4 · 3 wrong attempts = 0.
